✨ Sobre o Projeto
- Apresenta períodos arquitetônicos de maneira organizada
- Interface simples e visual
- Criado para facilitar estudos e consultas rápidas
- Desenvolvido enquanto dou meus primeiros passos no mundo da programação

✨Por que criei isso?
Sempre amei a forma como a arquitetura traduz história, cultura e narrativa.
E, entrando na área de tecnologia, quis começar com algo que fizesse sentido para mim, 
um projeto que conectasse quem eu fui como arquiteta e quem estou me tornando como desenvolvedora.
Este repositório é meu primeiro laboratório, onde exploro HTML, CSS e JavaScript ( Alura + Google + muita paciência ) 
enquanto construo algo útil para outros estudantes.
